# 國小 1200 單字迷宮：記憶之梯 (VocabQuest: Memory Ladder)

一款結合**教育部國中小基本英語字彙 1200 字**與**艾賓浩斯記憶階梯演算法**的輕量級 Roguelite 文字 RPG 網頁遊戲。

🎮 **線上直接玩**：[點此立即啟動冒險](https://<YOUR-GITHUB-USERNAME>.github.io/<REPO-NAME>/)

---

## 🌟 核心特色

1. **iPad 深度觸控與平板適配 (iPad & Tablet Optimized)**
   - 專門針對 iPad / 平板觸控螢幕最佳化：禁止誤觸縮放（`user-scalable=no`）、移除 300ms 點擊延遲、加大指尖觸控選項按鈕（高度 >= 58px）。
   - **iOS Safari 自動音效解鎖**：解決 iPad Safari 預設靜音問題，首觸即時解鎖 Web Audio API 打擊音效。

2. **多人獨立存檔與暱稱隔離 (Independent Per-Nickname Save Slots)**
   - **全新暱稱 = 全新開始**：只要輸入不同的新暱稱（例如：`0908`、`小明`、`Alex`），系統**自動開新存檔，從第 1 關全新開始**，絕不繼承他人關卡進度與星級！
   - **相同暱稱 = 讀取舊進度**：下次輸入同一個暱稱，無縫接續該玩家上次破到的關卡與記憶階梯。
   - **存檔管理抽屜**：登入畫面直接列出本機已存在的勇者名單（附帶通關進度與星數），可一鍵快速切換或刪除舊存檔。

3. **【全新】iPad 雙人同屏極速搶答對決 (1v1 Dual Split Battle)**
   - 兩位同學共用一臺 iPad 面對面競賽！
   - 螢幕左右分割為「🔵 藍方城堡」與「🔴 紅方城堡」，共用中央題目進行極速搶答。
   - 率先點中正確單字發動重擊，答錯失血，非常適合課堂分組競賽與家庭親子對抗！

2. **記憶階梯系統擺在首位 (Memory Ladder Spaced Repetition)**
   - 拋棄死記硬背，將詞彙分為 5 個記憶階梯（生疏探索 -> 反覆見習 -> 脈絡掌握 -> 賢者直覺 -> 永恆封印）。
   - 答對向上爬升、增強攻擊傷害；答錯跌落重溫、即時高亮情境解析。
   - 階梯 5「永恆封印」單字將永久登錄古老魔典，提供常駐增益。

2. **RPG 冒險與動態數值系統**
   - **HP（生命值）**：答錯遭受魔物反擊。
   - **SAN（理智值）**：施展武器技能的代價，理智過低時觸發視野混亂迷霧。
   - **Gold（金幣）**：戰鬥與過關獎勵，可用於黑市購買生命甘泉與凝神熏香。

3. **角色形態演化 (Character Evolution)**
   - 從「流浪學徒」逐漸成長晉升為「文字遊俠」、「符文咒劍士」與「真理大賢者」，獲得強力被動光環。

4. **沉浸式 Game Over 結算與接關機制**
   - 雙重死亡描繪（肉體力竭 vs 理智崩潰）。
   - 支援「再次接關（扣除 20% 分數重生）」、「重新挑戰」與「回到首頁保存成績」。

5. **零外部依賴、極致輕量**
   - 純 HTML5 + CSS3 + Vanilla JavaScript 原生打造。
   - 內建 Web Audio API 音效合成器，不需下載額外音訊檔即可具備打擊感與升級音效。
