# 國小 1200 單字迷宮：記憶之梯 (VocabQuest: Memory Ladder)

一款結合**教育部國中小基本英語字彙 1200 字**與**艾賓浩斯記憶階梯演算法**的輕量級 Roguelite 文字 RPG 網頁遊戲。

🎮 **線上直接玩**：[點此立即啟動冒險](https://<YOUR-GITHUB-USERNAME>.github.io/<REPO-NAME>/)

---

## 🌟 核心特色

1. **記憶階梯系統擺在首位 (Memory Ladder Spaced Repetition)**
   - 拋棄死記硬背，將詞彙分為 5 個記憶階梯（生疏探索 -> 反覆見習 -> 脈絡掌握 -> 賢者直覺 -> 永恆封印）。
   - 答對向上爬升、增強攻擊傷害；答錯跌落重溫、即時高亮情境解析。
   - 階梯 5「永恆封印」單字將永久登錄古老魔典，提供常駐增益。

2. **RPG 冒險與動態數值系統**
   - **HP（生命值）**：答錯遭受魔物反擊。
   - **SAN（理智值）**：施展武器技能的代價，理智過低時觸發視野混亂迷霧。
   - **Gold（金幣）**：戰鬥與過關獎勵，可用於黑市購買生命甘泉與凝神熏香。

3. **角色形態演化 (Character Evolution)**
   - 從「流浪學徒」逐漸成長晉升為「文字遊俠」、「符文咒劍士」與「真理大賢者」，獲得強力被動光環。

4. **沉浸式 Game Over 結算與接關機制**
   - 雙重死亡描繪（肉體力竭 vs 理智崩潰）。
   - 支援「再次接關（扣除 20% 分數重生）」、「重新挑戰」與「回到首頁保存成績」。

5. **零外部依賴、極致輕量**
   - 純 HTML5 + CSS3 + Vanilla JavaScript 原生打造。
   - 內建 Web Audio API 音效合成器，不需下載額外音訊檔即可具備打擊感與升級音效。
